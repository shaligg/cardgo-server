# 经济系统设计文档

## 1. 文档目标

本文档定义卡牌休闲游戏的经济系统。

经济系统负责控制资源产出、资源消耗、成长节奏、奖励价值和商业化边界。

本文档解决以下问题：

- 游戏有哪些资源。
- 每种资源从哪里产出。
- 每种资源消耗在哪里。
- 前 7 日资源压力如何设计。
- 卡牌升级和工坊升级如何消耗。
- 关卡、每日委托、无尽订单如何发奖。
- 活动币、友情币、钻石如何控制边界。
- 经济过剩或短缺时如何调节。

本文档不是最终数值表。

最终数值表需要在 Excel、CSV 或配置表中维护。

## 2. 经济定位

本项目是轻度休闲卡牌游戏。

经济系统的目标不是制造强压力，而是让玩家持续感到：

- 每局都有收获。
- 每天都有目标。
- 升级选择有取舍。
- 长期积累有意义。
- 付费或广告可以加速，但不破坏核心体验。

核心经济循环：

```text
主线关卡 / 每日委托 / 无尽订单 / 活动
  -> 获得金币、材料、卡牌资源、声望
  -> 升级卡牌、升级工坊、购买装饰
  -> 提升订单效率和流派能力
  -> 解锁更高章节和更多玩法
  -> 获得更高阶资源
```

经济系统要服务于三条成长线：

- 卡牌成长。
- 工坊成长。
- 收藏表达。

## 3. 设计原则

### 3.1 前期宽松，中期有选择

前 30 分钟不制造明显资源压力。

玩家应该顺利完成：

- 第一次订单。
- 第一次卡牌获得。
- 第一次卡牌升级。
- 第一次工坊升级。

第 1 天后开始出现轻微选择：

- 先升级卡牌。
- 先升级工坊。
- 先买装饰。
- 先攒材料。

但选择不能导致玩家被卡死。

### 3.2 核心资源少，扩展资源慎重

MVP 阶段资源种类要少。

第一阶段建议只保留：

- 金币。
- 钻石。
- 体力。
- 声望。
- 基础材料。
- 高级材料。
- 卡牌碎片。
- 友情币。
- 活动币。

其中友情币和活动币可以先只占位，不进入 MVP 主链路。

### 3.3 消耗要对应明确价值

每个消耗点必须让玩家知道“花出去换来了什么”。

好的消耗：

- 金币升级卡牌，卡牌效果变强。
- 金币和材料升级烤炉，面包订单收益提高。
- 友情币换材料箱，补足缺口。
- 活动币换限定装饰，满足收藏。

不好的消耗：

- 强制支付资源才能继续主线。
- 大量资源只用于清空库存。
- 玩家看不懂升级前后区别。

### 3.4 奖励要稳定，但不能无限膨胀

玩家需要稳定奖励形成安全感。

但如果金币、材料长期溢出，卡牌和工坊成长会失去价值。

经济控制重点：

- 订单奖励随章节稳定增长。
- 消耗曲线略高于产出曲线。
- 离线收益只做补充。
- 活动奖励不直接打穿主线经济。

### 3.5 付费不破坏公平感

商业化可以提供：

- 效率。
- 外观。
- 收藏。
- 轻度补偿。

商业化不应该提供：

- 直接碾压排行榜的数值。
- 必须购买才能通关的资源。
- 无限制的核心资源投放。
- 破坏关卡节奏的高额卡牌成长。

## 4. 资源总览

### 4.1 核心资产

| 资源 | 类型 | 用途 | MVP |
| --- | --- | --- | --- |
| gold | 金币 | 卡牌升级、设施升级、普通商店 | 是 |
| gem | 钻石 | 高级卡包、体力、礼包、加速 | 可占位 |
| stamina | 体力 | 主线关卡进入消耗 | 可选 |
| reputation | 声望 | 章节解锁、工坊成长门槛 | 是 |
| friendship_coin | 友情币 | 好友互助商店 | 后续 |

### 4.2 道具资源

| 资源 | 类型 | 用途 | MVP |
| --- | --- | --- | --- |
| basic_material | 基础材料 | 工坊升级、卡牌升级 | 是 |
| advanced_material | 高级材料 | 高阶设施、卡牌升级 | 是 |
| card_fragment_common | 普通卡牌碎片 | 普通卡升级或合成 | 是 |
| card_fragment_rare | 稀有卡牌碎片 | 稀有卡升级或合成 | 是 |
| decoration_fragment | 装饰碎片 | 装饰兑换 | 后续 |
| order_refresh_ticket | 订单刷新券 | 刷新订单 | 后续 |
| double_gold_ticket | 双倍金币券 | 单次奖励加成 | 后续 |

### 4.3 活动资源

| 资源 | 类型 | 用途 | 说明 |
| --- | --- | --- | --- |
| event_coin | 活动币 | 活动商店兑换 | 每个活动独立 |
| event_point | 活动积分 | 阶段奖励和排行 | 活动内有效 |
| event_ticket | 活动门票 | 活动关卡入场 | 视活动需要 |

活动资源默认不跨活动继承。

跨活动通用币容易造成囤积和兑换压力，MVP 不建议做。

### 4.4 资源层级

资源分为三层：

```text
基础循环资源
  gold / basic_material / card_fragment_common

中期成长资源
  advanced_material / card_fragment_rare / reputation

运营扩展资源
  gem / friendship_coin / event_coin / decoration_fragment
```

基础循环资源支撑每日成长。

中期成长资源支撑目标选择。

运营扩展资源支撑活动、社交和商业化。

## 5. 资源来源

### 5.1 主线关卡

主线关卡是第一阶段最主要的资源来源。

产出：

- 金币。
- 声望。
- 基础材料。
- 卡牌经验或卡牌碎片。
- 首通奖励。

设计原则：

- 首通奖励明显高于重复奖励。
- 失败也给少量金币或卡牌经验。
- 前 10 关奖励要支撑教学升级。
- 章节末尾奖励用于推动下一阶段。

建议比例：

| 奖励类型 | 首通 | 重复 |
| --- | --- | --- |
| 金币 | 100% | 40% 到 60% |
| 声望 | 100% | 0% |
| 材料 | 100% | 30% 到 60% |
| 卡牌资源 | 100% | 20% 到 50% |

### 5.2 每日委托

每日委托用于建立日常循环。

产出：

- 稳定金币。
- 基础材料。
- 少量高级材料。
- 每日活跃积分。

设计原则：

- 每日委托奖励稳定。
- 完成时间不宜超过 10 到 15 分钟。
- 奖励不要高到让主线失去价值。

建议：

```text
每日委托总奖励 ≈ 玩家当日主线 3 到 5 局基础奖励
```

### 5.3 无尽订单

无尽订单用于复玩和中后期消耗。

产出：

- 金币。
- 排行榜积分。
- 少量材料。
- 每周奖励。

设计原则：

- 单局奖励不超过主线同时间效率太多。
- 排行榜奖励以称号、头像框、装饰为主。
- 不把核心成长资源大量集中在排行榜。

### 5.4 工坊离线收益

离线收益用于回流和轻度补偿。

产出：

- 金币。
- 少量基础材料。

设计原则：

- 不超过主动游玩日收益的 10% 到 25%。
- 最大累计时间由展示柜等级决定。
- 可以做广告双倍，但双倍后仍不能超过经济红线。

### 5.5 好友互助

好友互助属于轻社交补充。

产出：

- 友情币。
- 少量基础材料。
- 少量金币。
- 装饰碎片。

设计原则：

- 每日次数限制。
- 奖励轻量。
- 不做玩家间自由交易。
- 不允许转移钻石、稀有卡牌、高价值道具。

### 5.6 活动

活动用于阶段性目标和内容更新。

产出：

- 活动币。
- 活动积分。
- 限定装饰。
- 材料箱。
- 卡包。

设计原则：

- 活动奖励不要完全替代主线。
- 活动币只在活动内闭环。
- 核心资源投放要有上限。
- 限定奖励优先用外观和收藏承载价值。

### 5.7 商业化

商业化来源：

- 月卡。
- 通行证。
- 礼包。
- 广告激励。
- 限定装饰。
- 高级卡包。

设计原则：

- 商业化不直接绕过所有成长。
- 广告激励每日次数有限。
- 礼包更适合做资源组合和外观组合。
- 高级卡包需要保底规则，避免负面体验。

## 6. 资源消耗

### 6.1 卡牌升级

卡牌升级是金币和卡牌碎片的主要消耗点。

消耗：

- 金币。
- 同名卡。
- 卡牌碎片。
- 高级材料。

建议：

| 卡牌等级 | 金币压力 | 碎片压力 | 目标 |
| --- | --- | --- | --- |
| Lv.1 -> Lv.2 | 低 | 低 | 新手教学 |
| Lv.2 -> Lv.3 | 中 | 中 | 第一日目标 |
| Lv.3 -> Lv.4 | 中高 | 高 | 第 3 到 7 日目标 |
| Lv.4 -> Lv.5 | 高 | 高 | 中长期目标 |

MVP 可以先只开放到 Lv.3。

### 6.2 工坊升级

工坊升级是金币和材料的主要消耗点。

消耗：

- 金币。
- 基础材料。
- 高级材料。

建议：

| 设施等级 | 时间目标 |
| --- | --- |
| Lv.1 -> Lv.2 | 教学即可完成 |
| Lv.2 -> Lv.3 | 2 到 3 局收益 |
| Lv.3 -> Lv.4 | 1 天轻度活跃 |
| Lv.4 -> Lv.5 | 2 到 3 天积累 |

工坊和卡牌要形成选择关系：

```text
卡牌升级：提升单局能力
工坊升级：提升长期效率
```

### 6.3 订单刷新

订单刷新是中后期轻消耗。

消耗：

- 金币。
- 订单刷新券。
- 钻石。

MVP 可以先不开放钻石刷新。

建议：

- 每日免费刷新 1 到 3 次。
- 金币刷新价格递增。
- 刷新券优先消耗。
- 钻石刷新只作为后续商业化入口。

### 6.4 商店购买

商店消耗：

- 金币。
- 钻石。
- 友情币。
- 活动币。

商店分类：

- 普通商店：金币购买基础材料、低阶装饰。
- 友情商店：友情币购买材料箱、装饰碎片。
- 活动商店：活动币兑换限定奖励。
- 高级商店：钻石购买卡包、礼包、皮肤。

### 6.5 装饰购买

装饰主要消耗：

- 金币。
- 活动币。
- 友情币。
- 钻石。

设计原则：

- 普通装饰可用金币购买。
- 活动装饰用活动币兑换。
- 高级装饰可商业化。
- 装饰数值加成必须有上限。

## 7. 前 7 日经济目标

### 7.1 D0 首次体验

目标：

- 完成核心教学。
- 获得第一批金币。
- 获得第一张新卡。
- 完成第一次设施升级。

资源体验：

- 不缺金币。
- 不缺基础材料。
- 不展示复杂资源。
- 不出现强付费提示。

建议目标：

| 时间 | 目标 |
| --- | --- |
| 1 分钟 | 完成第一个订单 |
| 5 分钟 | 获得第一张新卡 |
| 10 分钟 | 完成第一次卡牌升级 |
| 20 分钟 | 完成第一次工坊升级 |

### 7.2 D1 第一日

目标：

- 解锁卡组编辑。
- 解锁 2 到 3 个工坊设施。
- 完成 1 到 2 次卡牌升级。
- 感知到卡牌和工坊的资源选择。

资源压力：

- 金币略有压力。
- 基础材料够完成教学升级。
- 高级材料只少量出现。

建议：

```text
D1 总金币产出 >= D1 强制教学消耗 * 1.5
D1 总金币产出 <= D1 可选消耗总量 * 0.8
```

含义：

- 玩家不会被强制教学卡住。
- 玩家不能第一天买空所有成长。

### 7.3 D2 到 D3

目标：

- 形成初级流派。
- 开始每日委托。
- 开始无尽订单。
- 工坊设施出现升级选择。

资源压力：

- 金币成为主要选择资源。
- 基础材料开始出现短缺。
- 高级材料作为目标资源出现。

建议：

- 玩家能把 1 到 2 张核心卡升到 Lv.3。
- 玩家能把 1 到 2 个设施升到 Lv.3。
- 玩家不能同时把所有卡和所有设施都升满。

### 7.4 D4 到 D7

目标：

- 完成第一章。
- 体验活动入口。
- 体验无尽订单和中期目标。
- 开始关注装饰和社交奖励。

资源压力：

- 高级材料成为阶段目标。
- 卡牌碎片成为流派推进目标。
- 金币仍保持主要消耗地位。

建议：

```text
D7 普通玩家完成第一章
D7 轻度玩家仍有明确追赶目标
D7 重度玩家进入无尽订单和活动消耗
```

## 8. 首周资源曲线建议

### 8.1 金币曲线

金币是最核心资源。

建议金币来源占比：

| 来源 | D1 占比 | D7 占比 |
| --- | --- | --- |
| 主线关卡 | 70% | 35% |
| 每日委托 | 10% | 20% |
| 无尽订单 | 0% | 20% |
| 离线收益 | 10% | 10% |
| 活动 | 0% | 10% |
| 好友互助 | 0% | 5% |

金币消耗占比：

| 消耗 | D1 占比 | D7 占比 |
| --- | --- | --- |
| 卡牌升级 | 50% | 35% |
| 工坊升级 | 45% | 40% |
| 商店购买 | 5% | 10% |
| 订单刷新 | 0% | 10% |
| 装饰购买 | 0% | 5% |

### 8.2 材料曲线

材料用于工坊升级和少量卡牌升级。

MVP 不建议材料种类过多。

建议：

- 第一章只用基础材料和高级材料。
- 主题材料可以在第二章后引入。
- 材料箱用于补缺，不作为主要产出。

材料来源：

- 主线关卡。
- 每日委托。
- 工坊离线收益。
- 好友互助。
- 活动商店。

材料消耗：

- 工坊升级。
- 卡牌升级。
- 装饰制作。

### 8.3 卡牌碎片曲线

卡牌碎片用于卡牌升级和合成。

建议：

- 普通碎片投放稳定。
- 稀有碎片投放克制。
- 史诗碎片主要来自活动、卡包和阶段奖励。

MVP 可以先做：

- 普通碎片。
- 稀有碎片。

暂不做史诗碎片独立系统。

### 8.4 声望曲线

声望用于章节解锁和阶段成长。

设计原则：

- 声望主要来自首通和章节目标。
- 声望不作为高频消耗。
- 声望不要让玩家反复刷旧关。

推荐：

```text
声望 = 主线进度证明
金币/材料 = 日常成长资源
```

### 8.5 友情币曲线

友情币用于轻社交商店。

MVP 可只占位。

后续开放后：

- 每日互送获得少量友情币。
- 好友点赞获得少量友情币。
- 好友订单互助获得友情币。

友情币商店出售：

- 基础材料箱。
- 普通卡包碎片。
- 普通装饰碎片。
- 低价值便利道具。

不出售：

- 钻石。
- 高阶核心卡牌。
- 大量高级材料。

## 9. 奖励设计

### 9.1 奖励结构

所有奖励使用统一 `RewardItem`。

奖励包建议分层：

```text
RewardPack
- fixed_rewards
- random_rewards
- first_clear_rewards
- extra_rewards
```

说明：

- fixed_rewards：固定奖励。
- random_rewards：随机奖励。
- first_clear_rewards：首通奖励。
- extra_rewards：广告、活动、加成后的额外奖励。

### 9.2 主线关卡奖励

主线奖励由关卡难度和章节决定。

建议字段：

```text
LevelRewardConfig
- level_id
- first_clear_rewards
- repeat_rewards
- fail_rewards
- star_rewards
```

失败奖励：

- 少量金币。
- 少量卡牌经验。

失败奖励的目的不是鼓励失败，而是降低挫败感。

### 9.3 订单奖励

订单奖励来自订单配置。

订单奖励应和需求材料成正比。

基础关系：

```text
订单金币价值 = 需求资源价值 * 订单倍率 + 类型修正
```

类型修正：

- 普通订单：1.0。
- 加急订单：1.2 到 1.5。
- 高价值订单：1.5 到 2.0。
- 连锁订单：基础奖励低，额外效果高。
- Boss 订单：阶段奖励高。

### 9.4 每日委托奖励

每日委托奖励稳定，主要提供：

- 金币。
- 基础材料。
- 活跃奖励。

建议：

- 单个委托奖励不大。
- 完成全部委托有明显奖励。
- 不强制玩家完成全部委托。

### 9.5 无尽订单奖励

无尽订单奖励分为：

- 单局结算。
- 每日目标。
- 每周排行。

单局结算给金币和少量材料。

每周排行给外观、称号、头像框、装饰碎片。

避免给大量核心成长资源。

### 9.6 离线收益奖励

离线收益奖励公式：

```text
gold = base_gold_per_hour * effective_hours * showcase_rate * decoration_rate
material = base_material_per_hour * effective_hours * showcase_material_rate
```

控制线：

```text
离线日收益 <= 主动日收益 * 25%
```

MVP 可先简化：

```text
gold = player_level * 20 * hours * showcase_rate
basic_material = player_level * 2 * hours
```

## 10. 消耗设计

### 10.1 消耗结构

所有消耗使用统一 `CostItem`。

消耗配置建议：

```text
CostConfig
- cost_id
- scene
- costs          # CostItem 数组，字段为 item_id + count
- condition
```

scene 示例：

- card_upgrade。
- facility_upgrade。
- order_refresh。
- shop_buy。
- decoration_buy。

### 10.2 卡牌升级消耗建议

MVP 卡牌等级先做到 Lv.3。

示例：

| 稀有度 | Lv.1 -> Lv.2 | Lv.2 -> Lv.3 |
| --- | --- | --- |
| N | 80 金币 + 5 普通碎片 | 240 金币 + 15 普通碎片 |
| R | 120 金币 + 5 稀有碎片 | 360 金币 + 15 稀有碎片 |
| SR | 200 金币 + 8 稀有碎片 | 600 金币 + 25 稀有碎片 |
| SSR | MVP 暂不开放 | MVP 暂不开放 |

注意：

- 这是设计占位，不是最终数值。
- 最终数值要结合关卡产出表压测。

### 10.3 工坊升级消耗建议

示例：

| 等级 | 金币 | 基础材料 | 高级材料 |
| --- | --- | --- | --- |
| Lv.1 -> Lv.2 | 100 | 5 | 0 |
| Lv.2 -> Lv.3 | 300 | 20 | 0 |
| Lv.3 -> Lv.4 | 800 | 50 | 5 |
| Lv.4 -> Lv.5 | 1600 | 100 | 15 |

不同设施可以替换材料主题，但总价值接近。

### 10.4 订单刷新消耗建议

每日免费刷新：

- 初始 1 次。
- 订单板升级可增加到 3 次。

金币刷新价格：

| 当日次数 | 金币 |
| --- | --- |
| 1 | 50 |
| 2 | 100 |
| 3 | 200 |
| 4+ | 不建议开放或使用刷新券 |

### 10.5 商店消耗建议

普通商店：

- 金币买基础材料。
- 金币买普通装饰。
- 金币买低价值道具。

友情商店：

- 友情币买材料箱。
- 友情币买装饰碎片。
- 友情币买普通卡包碎片。

活动商店：

- 活动币换限定装饰。
- 活动币换材料箱。
- 活动币换卡包。

钻石商店：

- 高级卡包。
- 限定皮肤。
- 礼包。
- 体力补充。

## 11. 经济调节阀

### 11.1 产出调节

可以调节：

- 关卡金币奖励。
- 关卡材料掉落。
- 每日委托奖励。
- 离线收益系数。
- 活动商店兑换数量。
- 好友互助每日次数。

不建议频繁调节：

- 已售礼包价值。
- 玩家已获得资源。
- 卡牌核心效果。
- 付费卡包概率。

### 11.2 消耗调节

可以调节：

- 卡牌升级金币成本。
- 工坊升级材料成本。
- 订单刷新成本。
- 商店商品价格。

调节原则：

- 只上调未来内容，不回收已获得资源。
- 如果玩家大面积卡住，优先增加产出，而不是直接砍消耗。
- 如果资源大量溢出，优先增加可选消耗，不直接削弱奖励。

### 11.3 软回收

软回收用于解决资源溢出。

方式：

- 限时金币商店。
- 装饰购买。
- 订单刷新。
- 材料合成。
- 卡牌碎片兑换。

避免：

- 强制扣除。
- 过期清空核心资源。
- 让玩家感觉被惩罚。

### 11.4 补偿机制

资源短缺时可以增加：

- 每日登录奖励。
- 新手任务奖励。
- 首周目标奖励。
- 失败补偿。
- 活动材料箱。

补偿要明确原因，避免玩家形成“等补偿比玩游戏更赚”的习惯。

## 12. 商业化边界

### 12.1 月卡

月卡适合提供：

- 每日钻石。
- 每日金币。
- 少量材料箱。
- 离线收益加成。
- 专属装饰。

月卡不应提供：

- 独占强卡。
- 排行榜必需数值。
- 无限体力。

### 12.2 通行证

通行证适合提供：

- 长线任务奖励。
- 装饰。
- 头像框。
- 卡包。
- 材料箱。

通行证奖励应该和赛季活动绑定。

免费线也要有可感知奖励。

### 12.3 广告激励

广告适合场景：

- 双倍离线收益。
- 额外领取材料箱。
- 免费刷新订单。
- 关卡失败后领取安慰奖励。

广告限制：

- 每日次数上限。
- 不能连续强弹。
- 不能打断单局核心体验。

### 12.4 礼包

礼包类型：

- 新手礼包。
- 章节礼包。
- 工坊升级礼包。
- 卡牌成长礼包。
- 活动礼包。

礼包价值要明确，但不能让非付费玩家失去正常成长路径。

### 12.5 商业化红线

红线：

- 不出售无限制排行榜资源。
- 不用付费解锁主线必需能力。
- 不在新手前 10 分钟制造付费压力。
- 不让钻石直接替代所有核心资源。
- 不让高级卡包破坏卡牌流派平衡。

## 13. 数据指标

### 13.1 核心经济指标

每日观察：

- 金币产出总量。
- 金币消耗总量。
- 金币库存中位数。
- 基础材料库存中位数。
- 高级材料库存中位数。
- 卡牌碎片库存中位数。
- 卡牌升级次数。
- 工坊升级次数。
- 商店购买次数。

### 13.2 新手经济指标

观察：

- 首次获得金币时间。
- 首次卡牌升级时间。
- 首次工坊升级时间。
- 第 1 天金币缺口。
- 第 1 天材料缺口。
- 第 3 局前流失率。
- 第 5 局前流失率。

### 13.3 中期经济指标

观察：

- D3 卡牌 Lv.3 拥有率。
- D3 工坊 Lv.3 设施数量。
- D7 第一章完成率。
- D7 金币库存中位数。
- D7 材料库存中位数。
- 无尽订单参与率。
- 每日委托完成率。

### 13.4 商业化指标

观察：

- 广告观看率。
- 广告完成率。
- 月卡购买率。
- 新手礼包购买率。
- 卡包购买率。
- 购买后留存。

商业化指标必须和体验指标一起看。

如果收入上升但留存下降，需要重新评估压力设计。

## 14. 风险与处理

### 14.1 金币长期溢出

表现：

- 玩家金币库存持续上升。
- 卡牌和工坊升级率低。
- 商店购买率低。

原因可能是：

- 消耗点不足。
- 升级价值不明显。
- 商店缺少吸引力。
- 金币产出过高。

处理：

- 增加装饰和普通商店消耗。
- 强化卡牌升级反馈。
- 增加中期工坊升级目标。
- 下调未来关卡金币产出。

### 14.2 金币长期短缺

表现：

- 玩家卡牌升级停滞。
- 工坊升级停滞。
- 新手流失上升。

原因可能是：

- 强制消耗过多。
- 产出不足。
- 消耗曲线过陡。
- 玩家不知道从哪里获取资源。

处理：

- 增加每日委托金币。
- 增加失败补偿。
- 降低前期升级成本。
- 增加资源来源引导。

### 14.3 材料卡点过强

表现：

- 玩家金币足够但无法升级。
- 仓库材料结构不平衡。
- 某种材料长期缺口。

处理：

- 减少材料种类。
- 增加材料箱。
- 开放材料兑换。
- 调整订单掉落。

### 14.4 活动奖励冲击主线

表现：

- 活动期间主线参与下降。
- 活动奖励导致金币或材料大幅膨胀。
- 活动结束后经济失衡。

处理：

- 活动币活动内闭环。
- 活动核心奖励转向外观和收藏。
- 限制核心资源兑换次数。
- 活动前做产消模拟。

### 14.5 社交奖励被刷

表现：

- 友情币异常增长。
- 小号互刷材料。
- 好友互助收益超过日常玩法。

处理：

- 每日互助次数上限。
- 单账号、单设备、单 IP 风控。
- 友情币商店限制高价值资源。
- 好友关系建立后延迟开放高价值互助。

## 15. 配置结构

### 15.1 ItemConfig

`ItemConfig` 是资源、货币和道具的统一策划配置。它决定 `item_id` 是什么，以及该资源或道具应该存到哪里。

策划源文件使用 Excel，程序运行配置使用导出的 JSON。

```text
ItemConfig
- item_id
- key
- name
- item_type
- storage_type
- storage_key
- system
- stackable
- visible_in_bag
- max_limit
- display_order
- icon
- desc
```

### 15.2 RewardConfig

```text
RewardConfig
- reward_id
- scene
- fixed_rewards
- random_pool_id
- first_clear_extra
- weight
```

### 15.3 CostConfig

```text
CostConfig
- cost_id
- scene
- target_id
- target_level
- costs
```

### 15.4 EconomySceneConfig

```text
EconomySceneConfig
- scene
- daily_limit
- weekly_limit
- open_condition
- reward_group
- cost_group
```

### 15.5 EconomyLog

```text
EconomyLog
- log_id
- uid
- resource_type
- resource_id
- change
- before
- after
- scene
- req_id
- created_at
```

经济日志必须能回答：

- 资源从哪里来。
- 资源花到哪里去。
- 玩家是否重复领取。
- 某个版本是否造成异常产出。

## 16. 后端边界

### 16.1 AssetService

负责：

- 发奖。
- 扣费。
- 幂等。
- 资产流水。
- 资源上限。

不负责：

- 判断关卡是否完成。
- 判断卡牌升级效果。
- 判断工坊升级效果。

### 16.2 EconomyService

可选模块。

负责：

- 经济配置读取。
- 奖励包解析。
- 资源价值换算。
- 经济调试工具。
- 产消报表辅助。

MVP 可以不单独实现 EconomyService。

但建议至少在代码结构上预留配置和工具函数。

### 16.3 各业务模块

业务模块负责判断场景是否成立。

示例：

- CardService 判断卡牌能否升级。
- WorkshopService 判断设施能否升级。
- OrderService 判断订单是否完成。
- EventService 判断活动奖励是否可领取。

然后统一调用 AssetService 发奖或扣费。

## 17. 验收标准

### 17.1 新手验收

- 10 分钟内能完成第一次卡牌升级。
- 20 分钟内能完成第一次工坊升级。
- 前 30 分钟不会因为金币或材料不足卡住主线。
- 第 1 天能完成至少 1 到 2 次设施升级。

### 17.2 首周验收

- D3 玩家能形成一个初级流派。
- D7 普通玩家可完成第一章。
- D7 金币库存中位数不为 0，也不严重溢出。
- D7 至少 50% 活跃玩家完成过工坊升级。
- D7 至少 40% 活跃玩家完成过卡组编辑。

### 17.3 经济稳定验收

- 金币产消比在可控区间。
- 材料库存没有单一资源极端短缺。
- 离线收益不超过主动收益 25%。
- 活动奖励不冲击主线成长。
- 友情币无法转化为高价值核心资源。

### 17.4 研发验收

- 所有资源变更都有流水。
- 所有发奖和扣费支持 `req_id` 幂等。
- 所有奖励和消耗都走统一结构。
- 客户端不能直接决定发奖数量。
- 重复请求不会重复发奖或扣费。
