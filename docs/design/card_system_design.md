# 卡牌系统设计文档

## 1. 文档目标

本文档定义卡牌系统的核心规则、配置结构、卡组规则、成长规则、MVP 卡牌清单和程序实现边界。

总设计文档：

- `docs/design/card_casual_game_design.md`

相关后续文档：

- `docs/design/order_level_design.md`
- `docs/design/economy_design.md`
- `docs/design/workshop_system_design.md`

## 2. 系统定位

卡牌系统是本游戏的核心玩法系统。

卡牌不用于传统战斗，而用于生产资源、转换资源、复制资源、强化订单、触发连锁和改变局内节奏。

设计目标：

- 支撑 3 到 5 分钟短局。
- 让玩家通过组合卡牌获得“连起来了”的爽感。
- 为工坊升级、订单挑战、活动规则提供可持续扩展空间。
- 支撑多个流派，但避免复杂到休闲玩家无法理解。

## 3. 核心概念

### 3.1 卡牌

卡牌是玩家在局内操作的主要对象。

卡牌可以来自玩家卡组、关卡临时卡、活动临时卡或局内效果生成。

### 3.2 卡组

卡组是玩家局外配置的卡牌集合。玩家进入关卡时，系统根据卡组生成本局抽牌池。

### 3.3 手牌

手牌是玩家当前可使用的卡牌。每回合默认抽 1 张。

### 3.4 场上卡

部分卡牌打出后会留在场上，例如工匠卡和工具卡。场上卡会持续产出或提供被动效果。

### 3.5 局内资源

局内资源用于完成订单，本局结束后清空。

MVP 局内资源：

- `bread`：面包。
- `wood`：木材。
- `cloth`：布料。
- `magic`：魔法粉。
- `coin_tmp`：本局临时金币收益。

### 3.6 行动点

行动点是每回合可使用卡牌的成本资源。

MVP 默认：

- 每回合 3 行动点。
- 部分卡牌可降低费用或返还行动点。
- 行动点回合结束清空。

## 4. 卡牌类型

### 4.1 工匠卡

工匠卡是长期产能来源，打出后留在场上。

特点：

- 费用通常为 1 到 3。
- 每回合开始或特定条件下产出资源。
- 适合构成流派基础。

示例：

```text
面包猫
费用：1
效果：每回合开始时获得 1 面包。
```

### 4.2 材料卡

材料卡是一次性资源来源。

特点：

- 费用通常为 0 到 2。
- 打出后立即获得资源。
- 适合完成订单或触发连锁。

示例：

```text
小麦袋
费用：1
效果：获得 2 面包。
```

### 4.3 工具卡

工具卡是持续强化或触发器，打出后留在场上。

特点：

- 费用通常为 2 到 4。
- 提供资源增产、订单加成、抽牌或费用减免。
- 必须有触发次数上限，避免组合失控。

示例：

```text
烤炉
费用：2
效果：每当获得面包时，额外获得 1 面包。每回合最多触发 2 次。
```

### 4.4 订单辅助卡

订单辅助卡直接影响订单刷新、订单奖励或订单完成。

特点：

- 费用通常为 1 到 3。
- 不直接产生大量资源。
- 用于提高策略选择和局内节奏。

示例：

```text
订单刷新
费用：1
效果：刷新 1 个当前订单。
```

### 4.5 技巧卡

技巧卡是一次性策略操作。

特点：

- 用于抽牌、复制、降费、转换资源。
- 适合形成高级流派。
- 效果必须短、清楚、可预测。

示例：

```text
灵感一闪
费用：1
效果：抽 2 张牌。
```

## 5. 稀有度

MVP 稀有度：

| 稀有度 | 标识 | 定位 | 设计要求 |
|---|---|---|---|
| 普通 | N | 基础产能和基础材料 | 容易理解，易升级 |
| 稀有 | R | 明确组合能力 | 提供流派方向 |
| 史诗 | SR | 强触发和高效率 | 需要限制触发次数 |
| 传说 | SSR | 流派核心 | 改变玩法，但不硬卡主线 |

MVP 阶段建议先做：

- N：20 张。
- R：12 张。
- SR：6 张。
- SSR：2 张。

## 6. 费用规则

### 6.1 基础费用

费用使用行动点支付。

建议范围：

- 0 费：少量辅助卡，必须限制收益。
- 1 费：基础材料和基础工匠。
- 2 费：主要工具和中等收益卡。
- 3 费：强力工匠、强力工具、订单辅助。
- 4 费及以上：MVP 不建议大量使用。

### 6.2 费用设计原则

- 0 费卡不能直接产生大量资源。
- 持续型工具必须比一次性材料更贵。
- 抽牌和降费效果不能同时过强。
- 强连锁卡必须有每回合触发上限。

### 6.3 费用调整来源

可调整费用的系统：

- 卡牌升级。
- 工坊设施。
- 局内临时效果。
- 活动规则。
- 关卡规则。

## 7. 效果类型

### 7.1 立即获得资源

打出后立即获得局内资源。

配置示例：

```json
{
  "effect_type": "gain_resource",
  "resource": "bread",
  "value": 2
}
```

### 7.2 每回合产出

工匠卡常用效果。

触发时机：

- `turn_start`
- `turn_end`

配置示例：

```json
{
  "effect_type": "periodic_gain",
  "trigger": "turn_start",
  "resource": "bread",
  "value": 1
}
```

### 7.3 资源增产

工具卡常用效果。

必须配置触发上限。

```json
{
  "effect_type": "resource_bonus",
  "trigger_resource": "bread",
  "bonus_resource": "bread",
  "bonus_value": 1,
  "limit_per_turn": 2
}
```

### 7.4 资源转换

将一种资源转换成另一种资源。

```json
{
  "effect_type": "convert_resource",
  "from_resource": "wood",
  "from_value": 2,
  "to_resource": "coin_tmp",
  "to_value": 8
}
```

### 7.5 抽牌

```json
{
  "effect_type": "draw_card",
  "value": 2
}
```

限制：

- 抽牌卡需要费用。
- 抽牌加降费组合需要重点数值评审。

### 7.6 降低费用

```json
{
  "effect_type": "cost_reduce",
  "target": "next_card",
  "value": 1
}
```

限制：

- 单张卡最低费用为 0。
- MVP 不做负费用。

### 7.7 订单奖励加成

```json
{
  "effect_type": "order_reward_bonus",
  "target_order_tag": "bread",
  "bonus_coin": 3,
  "limit_per_turn": 2
}
```

### 7.8 订单刷新

```json
{
  "effect_type": "refresh_order",
  "value": 1
}
```

### 7.9 复制资源

```json
{
  "effect_type": "copy_resource",
  "target": "last_gained_resource",
  "rate": 0.5,
  "min_value": 1
}
```

限制：

- 必须有最小值和上限。
- MVP 建议只在 SR 或 SSR 卡中使用。

## 8. 触发时机

MVP 支持以下触发时机：

| 触发时机 | 说明 |
|---|---|
| `on_play` | 打出卡牌时 |
| `turn_start` | 回合开始 |
| `turn_end` | 回合结束 |
| `on_resource_gain` | 获得指定资源时 |
| `on_order_complete` | 完成订单时 |
| `on_combo` | 连锁触发时 |

触发结算顺序：

```text
玩家打牌
  -> 支付费用
  -> 执行 on_play
  -> 触发资源变化
  -> 检查 on_resource_gain
  -> 检查订单可完成
  -> 玩家提交订单
  -> 执行 on_order_complete
  -> 检查连锁奖励
```

## 9. 卡组规则

### 9.1 MVP 卡组规则

- 卡组数量：每个玩家初始 1 套，可后续解锁到 3 套。
- 每套卡组 20 张。
- 同名 N 卡最多 3 张。
- 同名 R 卡最多 2 张。
- 同名 SR 卡最多 2 张。
- 同名 SSR 卡最多 1 张。
- 卡组必须至少包含 8 张资源生产类卡。
- 卡组必须至少包含 3 张订单辅助或抽牌类卡。

### 9.2 抽牌规则

- 开局抽 5 张。
- 每回合开始抽 1 张。
- 牌库为空时，弃牌堆洗回牌库。
- 如果牌库和弃牌堆都为空，则不抽牌。

### 9.3 换牌规则

MVP 新手阶段可支持开局换牌。

规则：

- 每局开局可选择最多 2 张手牌重抽。
- 重抽后的牌不可再次重抽。
- 教学前 3 局可关闭换牌，降低认知成本。

## 10. 卡牌成长

### 10.1 升级方式

卡牌升级消耗：

- 金币。
- 卡牌碎片或同名卡。
- 卡牌经验。

MVP 推荐：

- 1 到 5 级。
- 普通卡最高 5 级。
- 稀有卡最高 5 级。
- 史诗卡最高 4 级。
- 传说卡最高 3 级。

### 10.2 升级收益

升级收益类型：

- 增加资源产出。
- 降低费用。
- 增加触发上限。
- 提升订单奖励。
- 解锁轻微被动。

### 10.3 升级边界

升级不能改变卡牌复杂度太多。玩家升级后应立刻理解收益。

推荐：

```text
Lv1：获得 2 面包
Lv2：获得 3 面包
Lv3：获得 3 面包，并抽 1 张牌
```

不推荐：

```text
Lv3 后改变为另一个复杂触发系统
```

## 11. 卡牌获取

### 11.1 免费获取

来源：

- 主线关卡。
- 每日委托。
- 无尽订单。
- 活跃宝箱。
- 活动商店。
- 好友互助商店。

### 11.2 付费获取

来源：

- 普通卡包。
- 高级卡包。
- 通行证。
- 月卡附加奖励。
- 主题礼包。

### 11.3 保底原则

付费抽卡需要保底，但 MVP 阶段可以先做简单版本。

建议：

- 每 10 抽至少 1 张 R。
- 每 50 抽至少 1 张 SR。
- SSR 不作为主线通关硬需求。

## 12. 流派设计

### 12.1 面包流

定位：新手稳定产出。

核心机制：

- 快速获得面包。
- 低费完成订单。
- 稳定金币收益。

弱点：

- 高级订单上限较低。
- 复合资源订单需要外部补充。

### 12.2 木工流

定位：慢启动高收益。

核心机制：

- 木材产出较慢。
- 木工订单奖励高。
- 工具卡收益明显。

弱点：

- 前几回合容易卡手。
- 加急订单压力较大。

### 12.3 布艺流

定位：复制和爆发。

核心机制：

- 复制资源。
- 一回合完成多个订单。
- 连锁收益高。

弱点：

- 依赖组合。
- 操作成本较高。

### 12.4 魔法流

定位：随机和高上限。

核心机制：

- 随机资源。
- 变换订单。
- 生成临时卡。

弱点：

- 稳定性较差。
- 不适合新手主线前期。

### 12.5 招财流

定位：金币收益。

核心机制：

- 完成订单返利。
- 提高临时金币收益。
- 配合低级订单快速滚动。

弱点：

- 对订单刷新质量敏感。
- 资源生产能力一般。

### 12.6 压缩流

定位：高级循环。

核心机制：

- 抽牌。
- 删牌。
- 降费。
- 快速循环核心卡。

弱点：

- 理解门槛高。
- 容易产生数值失控。

## 15. 程序实现边界

### 15.1 服务端负责

- 玩家卡牌库存。
- 卡组保存和校验。
- 卡牌升级。
- 局内卡牌效果结算。
- 结算奖励校验。
- 关键操作幂等。

### 15.2 客户端负责

- 卡牌展示。
- 卡组编辑交互。
- 局内拖拽和出牌表现。
- 资源变化动画。
- 连锁反馈。
- 卡牌升级展示。

### 15.3 配置层负责

- 卡牌基础属性。
- 卡牌效果参数。
- 升级消耗。
- 卡牌获取来源。
- 卡牌解锁条件。

## 16. 验收标准

### 16.1 玩法验收

- 玩家能在 3 局内理解卡牌用于完成订单。
- 每个流派至少有 1 个基础组合。
- 单局至少能稳定触发 1 次连锁。
- 40 张 MVP 卡牌都能在配置表中表达。

### 16.2 程序验收

- 能读取卡牌配置。
- 能保存玩家卡牌库存。
- 能保存和校验卡组。
- 能执行 MVP 效果类型。
- 能处理断线恢复后的手牌和场上卡。
- 能防止重复结算奖励。

### 16.3 数值验收

- 不存在单卡无限循环。
- 0 费卡不会单独产生高收益。
- 抽牌和降费组合有触发上限。
- 前 10 关推荐卡组可稳定通过。

### 16.4 QA 验收

- 每张卡可以单独验证效果。
- 每个触发时机可以被构造测试。
- 每个流派可以完成至少 3 个对应订单。
- 错误卡组配置能被系统拦截。

## 17. 暂缓内容

MVP 暂缓：

- 复杂关键字系统。
- 卡牌皮肤独立属性。
- 玩家间卡牌交易。
- 战斗内卡牌随机生成池。
- 多卡牌同时复杂结算链。
- 负费用机制。
- 无限模式专属卡牌。
